# Portable hulpmiddelen

De vier uitvoerbare bestanden staan in het volledige Windows-releasepakket:
`yt-dlp.exe`, `ffmpeg.exe`, `ffprobe.exe` en `deno.exe`.

Download het pakket via de Releases-pagina. De broncode-ZIP van GitHub bevat deze bestanden niet.
`versions.json` en `SHA256SUMS.txt` worden bij het verpakken gemaakt. `deno-source.json` vermeldt de officiële download en de SHA-256 van het oorspronkelijke Deno-archief.
